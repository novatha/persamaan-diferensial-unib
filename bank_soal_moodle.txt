// MINGGU 1: Pengantar & Klasifikasi Persamaan Diferensial
// ----------------------------------------------------------------------------
Orde dan derajat dari persamaan diferensial $\left(\frac{d^3 y}{dx^3}\right)^2 + 4\left(\frac{dy}{dx}\right)^5 - y = \sin(x)$ berturut-turut adalah... {
=Orde 3 dan derajat 2
~Orde 3 dan derajat 5
~Orde 5 dan derajat 3
~Orde 2 dan derajat 3
}

Persamaan diferensial berikut yang tergolong sebagai Persamaan Diferensial Biasa (PDB) linier adalah... {
=$\frac{d^2 y}{dx^2} + 5x \frac{dy}{dx} + 2y = e^x$
~$\frac{d^2 y}{dx^2} + y \frac{dy}{dx} = 0$
~$\left(\frac{dy}{dx}\right)^2 + 4y = \cos(x)$
~$\frac{d^2 y}{dx^2} + \sin(y) = 0$
}

Berdasarkan Hukum Tegangan Kirchhoff (KVL), model matematika arus $i(t)$ pada rangkaian seri RL dengan sumber tegangan $V(t)$ menghasilkan persamaan... {
=PDB linier orde 1: $L\frac{di}{dt} + Ri = V(t)$
~PDB non-linier orde 1: $R\frac{di}{dt} + Li^2 = V(t)$
~PDB homogen orde 2: $L\frac{d^2i}{dt^2} + Ri = 0$
~PDP linier orde 1: $\frac{\partial i}{\partial t} + \frac{\partial i}{\partial x} = V(t)$
}

// ----------------------------------------------------------------------------
// MINGGU 2: PDB Orde 1 (Separabel, Eksak, dan Faktor Integrasi)
// ----------------------------------------------------------------------------
Solusi umum dari PDB separabel $\frac{dy}{dx} = \frac{x}{y}$ adalah... {
=$y^2 - x^2 = C$
~$y^2 + x^2 = C$
~$y = x^2 + C$
~$y = \ln(x) + C$
}

Suatu PDB dalam bentuk diferensial $M(x,y)dx + N(x,y)dy = 0$ dikatakan EKSAK jika memenuhi syarat perlu dan cukup... {
=$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$
~$\frac{\partial M}{\partial x} = \frac{\partial N}{\partial y}$
~$\frac{\partial M}{\partial y} = -\frac{\partial N}{\partial x}$
~$\frac{\partial^2 M}{\partial x^2} + \frac{\partial^2 N}{\partial y^2} = 0$
}

Faktor integrasi $\mu(x)$ untuk menyelesaikan PDB linier standar $\frac{dy}{dx} + P(x)y = Q(x)$ dirumuskan sebagai... {
=$\mu(x) = e^{\int P(x) dx}$
~$\mu(x) = e^{-\int P(x) dx}$
~$\mu(x) = \int P(x) dx$
~$\mu(x) = e^{\int Q(x) dx}$
}

=$30^\circ\text{C}$

=$55^\circ\text{C}$

}

// MINGGU 4: PDB Orde 2 Linier Homogen Koefisien Konstan
// ----------------------------------------------------------------------------
Jika persamaan karakteristik dari PDB $a y'' + b y' + c y = 0$ memiliki diskriminan $D = b^2 - 4ac < 0$ dengan akar kompleks $r = \alpha \pm j\beta$, maka bentuk solusi umumnya adalah... {
=$y(x) = e^{\alpha x}\left(C_1 \cos(\beta x) + C_2 \sin(\beta x)\right)$
~$y(x) = C_1 e^{\alpha x} + C_2 e^{\beta x}$
~$y(x) = (C_1 + C_2 x)e^{\alpha x}$
~$y(x) = C_1 \cosh(\alpha x) + C_2 \sinh(\beta x)$
}

Akar-akar karakteristik dari PDB osilasi bebas $y'' + 16y = 0$ adalah... {
=$r = \pm 4j$
~$r = \pm 4$
~$r = -4$ (akar kembar)
~$r = 0$ dan $r = 16$
}

Rangkaian LC murni tanpa resistansi ($R=0$) dimodelkan oleh $L\frac{d^2i}{dt^2} + \frac{1}{C}i = 0$. Frekuensi sudut natural $\omega_0$ osilasi rangkaian tersebut adalah... {
=$\omega_0 = \frac{1}{\sqrt{LC}}$
~$\omega_0 = \sqrt{LC}$
~$\omega_0 = \frac{L}{C}$
~$\omega_0 = \frac{R}{2L}$
}

// ----------------------------------------------------------------------------
// MINGGU 5: PDB Orde 2 Non-Homogen & RLC Seri
// ----------------------------------------------------------------------------
Solusi total dari PDB linier non-homogen $a y'' + b y' + c y = g(x)$ selalu dinyatakan sebagai... {
=$y(x) = y_h(x) + y_p(x)$ (solusi homogen ditambah solusi partikular)
~$y(x) = y_h(x) \cdot y_p(x)$ (perkalian solusi homogen dan partikular)
~$y(x) = y_p(x) - y_h(x)$
~$y(x) = \frac{y_h(x)}{y_p(x)}$
}

Pada rangkaian RLC seri, jika koefisien redaman $\alpha = \frac{R}{2L}$ bernilai LEBIH KECIL daripada frekuensi natural $\omega_0 = \frac{1}{\sqrt{LC}}$ ($\alpha < \omega_0$), maka respons transien rangkaian bertipe... {
=Underdamped (Kurang Redam / Berosilasi teredam)
~Critically Damped (Redam Kritis)
~Overdamped (Lebih Redam / Tanpa osilasi lambat)
~Tak teredam sempurna
}

Jika ruas kanan PDB adalah $g(x) = 5e^{2x}$, dan nilai $r=2$ merupakan salah satu akar dari solusi homogen $y_h(x)$, maka menurut aturan modifikasi resonansi, tebakan solusi partikular $y_p(x)$ harus berbentuk... {
=$y_p = A x e^{2x}$
~$y_p = A e^{2x}$
~$y_p = A x^2 e^{2x}$
~$y_p = (A x + B)e^{2x}$
}

// MINGGU 6: Transformasi Laplace Dasar
// ----------------------------------------------------------------------------
Transformasi Laplace dari fungsi konstan $f(t) = 1$ untuk $s > 0$ didefinisikan sebagai... {
=$F(s) = \frac{1}{s}$
~$F(s) = \frac{1}{s^2}$
~$F(s) = s$
~$F(s) = 1$
}

Berdasarkan Teorema Pergeseran Pertama (*First Shifting Theorem*), jika $\mathcal{L}\{\cos(3t)\} = \frac{s}{s^2 + 9}$, maka $\mathcal{L}\{e^{-2t}\cos(3t)\}$ adalah... {
=$\frac{s+2}{(s+2)^2 + 9}$
~$\frac{s-2}{(s-2)^2 + 9}$
~$\frac{s}{(s+2)^2 + 9}$
~$\frac{s+2}{s^2 + 9}$
}

Transformasi Laplace dari turunan kedua $\mathcal{L}\{f''(t)\}$ dengan kondisi awal $f(0)$ dan $f'(0)$ adalah... {
=$s^2 F(s) - s f(0) - f'(0)$
=$s^2 F(s) - f(0) - s f'(0)$
=$s^2 F(s) + s f(0) + f'(0)$
=$\frac{F(s)}{s^2} - f(0)$
}

// MINGGU 9: Pengantar PDP & Analisis Deret Fourier
// ----------------------------------------------------------------------------
Persamaan diferensial $\frac{\partial^2 u}{\partial t^2} = v^2 \frac{\partial^2 u}{\partial x^2}$ diklasifikasikan sebagai... {
=Persamaan Diferensial Parsial (PDP) orde 2
~Persamaan Diferensial Biasa (PDB) orde 2
~PDB linier orde 1
~PDP non-linier orde 1
}

Jika suatu fungsi periodik $f(t)$ memiliki simetri GENAP ($f(-t) = f(t)$), maka dalam ekspansi Deret Fouriernya... {
=Seluruh koefisien sinus bernilai nol ($b_n = 0$)
~Seluruh koefisien kosinus bernilai nol ($a_n = 0$)
~Nilai rata-rata $a_0 = 0$
~Seluruh koefisien $a_n$ dan $b_n$ bernilai sama
}

Koefisien nilai rata-rata $a_0$ pada Deret Fourier untuk fungsi dengan periode $T = 2L$ dirumuskan sebagai... {
=$a_0 = \frac{1}{2L} \int_{-L}^{L} f(t) \, dt$
=$a_0 = \frac{1}{L} \int_{-L}^{L} f(t) \, dt$
=$a_0 = \int_{0}^{L} f(t) \, dt$
=$a_0 = \frac{2}{L} \int_{0}^{L} f(t)\cos(nt) \, dt$
}

// ----------------------------------------------------------------------------
// MINGGU 10: Solusi PDP Metode Pemisahan Variabel
// ----------------------------------------------------------------------------
Metode pemisahan variabel mengasumsikan bahwa solusi fungsi multi-variabel $u(x,t)$ dapat dituliskan sebagai... {
=Perkalian dua fungsi satu variabel: $u(x,t) = X(x) \cdot T(t)$
~Penjumlahan linear: $u(x,t) = X(x) + T(t)$
~Pembagian fungsi: $u(x,t) = \frac{X(x)}{T(t)}$
~Fungsi komposisi: $u(x,t) = X(T(t))$
}

Pada penyelesaian persamaan difusi panas 1D menggunakan pemisahan variabel, konstanta pemisahan harus dipilih bernilai NEGATIF ($-\lambda^2$) karena alasan fisik... {
=Agar solusi waktu $T(t)$ meluruh stabil secara eksponensial menuju kesetimbangan termal
~Agar suhu meningkat secara eksponensial menuju tak terhingga
~Agar tidak diperlukan syarat batas pada ujung konduktor
~Agar solusi spasial berbentuk polinomial orde tinggi
}

Masalah nilai batas spasial $X''(x) + \lambda^2 X(x) = 0$ dengan syarat batas Dirichlet $X(0) = 0$ dan $X(L) = 0$ menghasilkan nilai eigen... {
=$\lambda_n = \frac{n\pi}{L}, \quad n = 1, 2, 3, \dots$
~$\lambda_n = \frac{(2n-1)\pi}{2L}$
~$\lambda_n = n L \pi$
~$\lambda_n = \frac{n^2 \pi^2}{L^2}$
}

// MINGGU 11: Persamaan Gelombang 1D pada Saluran Transmisi
// ----------------------------------------------------------------------------
Kecepatan rambat gelombang tegangan dan arus $v$ pada saluran transmisi tanpa rugi-rugi (*lossless transmission line*) dengan induktansi per meter $L'$ dan kapasitansi per meter $C'$ adalah... {
=$v = \frac{1}{\sqrt{L' C'}}$
~$v = \sqrt{L' C'}$
~$v = \frac{L'}{C'}$
~$v = \frac{1}{L' C'}$
}

Solusi d'Alembert menyatakan bahwa perambatan gelombang 1D merupakan superposisi dari dua gelombang berjalan... {
=$u(x,t) = f(x - ct) + g(x + ct)$
~$u(x,t) = f(x) \cdot g(ct)$
~$u(x,t) = f(x - ct) \cdot g(x + ct)$
~$u(x,t) = f(x^2 - c^2 t^2)$
}

Pada ujung saluran transmisi yang terhubung singkat (*short circuit* / ground), syarat batas yang berlaku untuk gelombang tegangan $v(L,t)$ adalah... {
=Batas Dirichlet: $v(L,t) = 0$ (koefisien refleksi $\Gamma = -1$)
~Batas Neumann: $\frac{\partial v}{\partial x}(L,t) = 0$ (koefisien refleksi $\Gamma = +1$)
~Batas Cauchy: $v(L,t) = \infty$
~Batas Robin: $v(L,t) + \frac{\partial v}{\partial t} = 1$
}

// MINGGU 13: Persamaan Laplace 2D & Medan Elektrostatik
// ----------------------------------------------------------------------------
Persamaan Laplace 2D yang memodelkan potensial elektrostatik $V(x,y)$ di dalam ruang bebas muatan adalah... {
=$\frac{\partial^2 V}{\partial x^2} + \frac{\partial^2 V}{\partial y^2} = 0$
~$\frac{\partial^2 V}{\partial x^2} - \frac{\partial^2 V}{\partial y^2} = 0$
~$\frac{\partial V}{\partial x} + \frac{\partial V}{\partial y} = 0$
~$\frac{\partial^2 V}{\partial x^2} + \frac{\partial^2 V}{\partial y^2} = -\frac{\rho_v}{\varepsilon}$
}

Berdasarkan *Mean-Value Property* dari fungsi harmonik solusi Laplace 2D, nilai potensial pada titik pusat suatu grid numerik 4-titik tetangga sama dengan... {
=Nilai rata-rata dari 4 titik di sekelilingnya: $V_{i,j} = \frac{1}{4}(V_{i+1,j} + V_{i-1,j} + V_{i,j+1} + V_{i,j-1})$
~Penjumlahan dari 4 titik tetangga: $V_{i+1,j} + V_{i-1,j} + V_{i,j+1} + V_{i,j-1}$
~Nilai maksimum dari 4 titik di sekelilingnya
~Selisih antara titik horizontal dan vertikal
}

Menurut Prinsip Ekstremum pada Persamaan Laplace, nilai potensial maksimum dan minimum suatu medan elektrostatik... {
=Hanya dapat terjadi pada batas (*boundary*) domain, bukan di dalam interior terbuka
~Selalu terjadi persis di titik pusat domain
~Dapat berada di sembarang titik lokal di dalam rongga
~Selalu bernilai nol di semua titik
}

// MINGGU 14: Fungsi Khusus — Persamaan Bessel & Efek Kulit
// ----------------------------------------------------------------------------
Transformasi operator Laplacian $\nabla^2 u$ ke dalam koordinat silinder $(r, \theta, z)$ secara alami memunculkan... {
=Persamaan Diferensial Bessel: $x^2 y'' + x y' + (x^2 - \nu^2)y = 0$
~Persamaan Polinomial Legendre: $(1-x^2)y'' - 2x y' + n(n+1)y = 0$
~Persamaan Diferensial Hermite: $y'' - 2x y' + 2n y = 0$
~Persamaan Diferensial Chebyshev: $(1-x^2)y'' - x y' + n^2 y = 0$
}

Pada pemodelan rapat arus kabel silinder tembaga pejal, fungsi Bessel jenis kedua $Y_\nu(x)$ tidak diikutsertakan ($C_2 = 0$) karena... {
=Nilai $Y_\nu(x)$ menuju $-\infty$ saat $x \to 0$ (singular di titik pusat sumbu kabel)
~Nilai $Y_\nu(x)$ selalu bernilai nol di semua titik
~Fungsi $Y_\nu(x)$ tidak dapat diturunkan
~Nilai $Y_\nu(x)$ hanya berlaku untuk bilangan negatif
}

Fenomena Efek Kulit (*Skin Effect*) pada konduktor yang dialiri arus bolak-balik (AC) frekuensi tinggi menyebabkan rapat arus... {
=Terpusat mengumpul di dekat permukaan luar kabel
=Terpusat mengumpul di inti tengah kabel
=Terdistribusi merata di seluruh penampang kabel
=Menghilang secara total di seluruh kabel
}

// ----------------------------------------------------------------------------
// MINGGU 15: Sintesis PDP dalam Persamaan Maxwell & Gelombang EM
// ----------------------------------------------------------------------------
Hukum induksi Faraday dalam bentuk diferensial dinyatakan oleh persamaan... {
=$\nabla \times \mathbf{E} = -\frac{\partial \mathbf{B}}{\partial t}$
~$\nabla \cdot \mathbf{D} = \rho_v$
~$\nabla \cdot \mathbf{B} = 0$
~$\nabla \times \mathbf{H} = \mathbf{J} + \frac{\partial \mathbf{D}}{\partial t}$
}

Kecepatan rambat gelombang elektromagnetik 3D di ruang hampa ($c$) diturunkan dari persamaan Maxwell sebagai... {
=$c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}$
~$c = \sqrt{\mu_0 \varepsilon_0}$
~$c = \frac{\mu_0}{\varepsilon_0}$
~$c = \mu_0 \varepsilon_0$
}

Persamaan gelombang elektromagnetik 3D untuk vektor medan listrik $\mathbf{E}$ di ruang bebas muatan adalah... {
=$\nabla^2 \mathbf{E} = \mu_0 \varepsilon_0 \frac{\partial^2 \mathbf{E}}{\partial t^2}$
~$\nabla^2 \mathbf{E} = \frac{\partial \mathbf{E}}{\partial t}$
~$\nabla \cdot \mathbf{E} = \mu_0 \varepsilon_0 \mathbf{E}$
~$\nabla \times \mathbf{E} = \mu_0 \varepsilon_0 \frac{\partial^2 \mathbf{E}}{\partial t^2}$
}
