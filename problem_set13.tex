\section*{Daftar Soal (Level Kognitif C1 - C6)}

\begin{enumerate}[label=\textbf{\arabic*.}]
    \item \textbf{(C1 - Mengingat)} Tuliskan persamaan Laplace 2D dalam sistem koordinat kartesian.
    \item \textbf{(C2 - Memahami)} Jelaskan arti fisis dari persamaan Laplace $\nabla^2 V = 0$ dalam konteks elektrostatika. Mengapa ruas kanan bernilai nol?
    \item \textbf{(C3 - Mengaplikasikan)} Terapkan metode pemisahan variabel $V(x,y) = X(x)Y(y)$ pada persamaan Laplace 2D. Turunkan langkah demi langkah hingga mendapatkan dua Persamaan Diferensial Biasa (PDB) orde 2.
    \item \textbf{(C4 - Menganalisis)} Diberikan sebuah daerah persegi panjang $0 \le x \le a$ dan $0 \le y \le b$. Jika syarat batas adalah $V(0,y) = 0$, $V(a,y) = 0$, dan $V(x,0) = 0$, analisislah bagaimana pemilihan konstanta pemisahan (misalnya $-k^2$) akan memengaruhi bentuk solusi, dan jelaskan mengapa fungsi trigonometri dipilih untuk arah-$x$.
    \item \textbf{(C5 - Mengevaluasi)} Seseorang mengklaim bahwa solusi untuk $V(x,y)$ pada persegi panjang dengan tiga sisi di-ground ($V=0$) dan satu sisi ($y=b$) memiliki potensial $V_0$ berbentuk $V(x,y) = \sum_{n=1}^{\infty} C_n \sin\left(\frac{n\pi x}{a}\right) \sinh\left(\frac{n\pi y}{a}\right)$. Evaluasi dan buktikan kebenaran bentuk solusi ini menggunakan syarat batas yang diberikan!
    \item \textbf{(C6 - Mencipta)} Formulasikan sebuah masalah nilai batas (Boundary Value Problem) baru untuk distribusi potensial 2D dalam sebuah penampang pelat logam, berikan spesifikasi dimensi dan syarat batas Anda sendiri, lalu rumuskan ekspresi integral untuk mencari koefisien deret Fourier-nya.
\end{enumerate}
